Pyenvのコマンド一覧

Pyenv

インストール可能なバージョン一覧表示

pyenv install –list

特定のバージョンをインストール

pyenv install 3.6.1 # python 3.6.1をインストール

インストールされているPythonバージョン一覧を表示

pyenv versions

現在のバージョンを確認

python –version

globalコマンドを使ってデフォルトのPythonバージョンを変更

pyenv global 3.6.1 # デフォルトバージョンを3.6.1に変更
