Install OpenFOAM for Mac

目次
  • 補足
  • スクリプトの実行

準備

Install Docker for Mac

Dockerイメージの取得する方法

docker pull opencfd/openfoam-run

補足

link

  • run : a small-footprint runtime-only image

  • dev : runtime with OpenFOAM development environment

  • default : just-give-me-everything image

コンテナの作成

docker create -it opencfd/openfoam-run

コンテナのスタート

docker start コンテナID

コンテナ内のOpenFOAM実行方法

スクリプトの実行

https://develop.openfoam.com/packaging/containers/-/raw/main/openfoam-dockerをダウンロードしてきて、パスの通った場所に保管。

下記のコマンドを実行

chmod +x openfoam-docker ln -sf openfoam-docker openfoam2212-run

ヘルプの確認 openfoam-docker -help
