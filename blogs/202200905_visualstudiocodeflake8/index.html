Visual Studio CodeにFlake8を導入する方法

Python
目次
  • Settingsをクリック
  • linterを無効化する

flake8のインストール

pip install flake8

VS Codeの既存のLintであるpylintを無効化する

Settingsをクリック

linterを無効化する

検索窓でpython.linting.pylintEnabledと入力し検索 > Linting: PyLint Enabledを無効化

flake8に設定する

検索窓でpython.linting.flake8Enabledと入力し検索 > Linting: Flake8 Enabledを無効化

完了

これでソースファイル保存時にコードがPEP8に準拠しているか検証される
