ProtocolBufferのインストール

パッケージマネージャを利用したインストール

Linuxの場合

apt install -y protobuf-compiler
protoc --version

Macの場合

brew install protobuf
protoc --version

Windows(Linux, Mac以外のOSの場合)

  1. 手動でインストール
  2. 解凍
  3. パスに追加

あるいは

  1. コマンドからファイル取得
    1. PB_REL="https://github.com/protocolbuffers/protobuf/releases"
    2. curl -LO $PB_REL/download/v3.15.8/protoc-3.15.8-linux-x86_64.zip
  2. 解凍
    1. unzip protoc-3.15.8-linux-x86_64.zip -d $HOME/.local
  3. パスのアップデート
    1. export PATH="$PATH:$HOME/.local/bin"

参考文献

https://grpc.io/docs/protoc-installation/
